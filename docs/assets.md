# Assets

The three house portraits in `public/portraits` are original SVG illustrations created for this sample and distributed under the repository's MIT license. They are fictional exhibition identities, not platform champions.

Combat accents are synthesized in the browser by `src/client/sound.ts`; no commercial music or sound library is copied.

The stylesheet requests DM Sans and Barlow Condensed from Google Fonts, with system fallbacks. Both families are distributed under the SIL Open Font License by their upstream authors. For installations that require fully local assets, self-host those fonts with their license files or remove the import and use the fallbacks.

ElevenLabs audio is generated using the operator's provider account and chosen voice. Check that account and voice's usage rights; the MIT repository license does not replace them. Provider media stays in the game database and is not committed.

Champion portraits and public token metadata come from BattleBots through its signed entry receipt. The game retains the authorized public identity snapshot for the match/replay.

Upstream font licenses: [DM Sans](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt) and [Barlow Condensed](https://github.com/google/fonts/blob/main/ofl/barlowcondensed/OFL.txt).
